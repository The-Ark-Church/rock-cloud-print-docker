Blank labels

Prints a stack of pre-coded blank check-in labels for people to fill in by hand. Every copy carries one security code shared by all of its labels, so a child's tag and a parent's receipt still match at pickup.

This needs nothing from Rock, which is the whole point — the stack exists for the times Rock cannot be reached. Print it in advance, and choose a printer that is not serving check-in.

Stored labels
